## 一、项目设计与实现方案

在 PC Linux 环境下通过 Waydroid 运行音乐节奏游戏面临两大核心痛点：
1. **触控输入延迟与长条断连**：Android 系统对普通鼠标或虚拟点击的响应有延迟，且快速连击同一轨容易出现触点事件被合并丢弃；
2. **KDE Wayland 窗口置顶受限**：Wayland 协议限制应用窗口随意置顶与全局坐标定位，打歌时缺少判定线视觉参考。

本项目采用纯原生双引擎架构彻底解决了上述问题：

```
+-------------------------------------------------------------------+
|                        物理键盘原始输入                            |
+---------------------------------+---------------------------------+
                                  |
            [evdev 监听原始扫描码，无窗口系统延迟]
                                  v
+-------------------------------------------------------------------+
|               pjsk_keybinds.py 触控映射引擎                       |
|  - 虚拟硬件触控板 (uinput MT Type B，10 槽位并发)                  |
|  - FIFO 槽位调度算法 (彻底杜绝同轨高速连击漏音符)                 |
|  - 亚像素微动长按心跳 (30ms 周期，彻底消除长条断连)                |
|  - 4 阶微步插值上滑 (Space 触发 280px 向上 Flick 手势)             |
+---------------------------------+---------------------------------+
                                  |
                    [写入 Linux 内核 uinput 设备]
                                  v
+-------------------------------------------------------------------+
|              Waydroid (Android 容器 / PJSK 游戏)                  |
+-------------------------------------------------------------------+
                                  ^
                                  |
+---------------------------------+---------------------------------+
|               pjsk_overlay.py 屏幕透明 HUD 辅助                   |
|  - PySide6 (Qt6) 纯透明、无边框、无任务栏图元                      |
|  - 鼠标事件完全穿透 (WA_TransparentForMouseEvents)                |
|  - KWin Scripting D-Bus 强制定格置顶 (keepAbove = true)           |
|  - 判定线大键高对比底板 + 正下方大尺寸合击徽标 (不遮挡下落音符)   |
+-------------------------------------------------------------------+
```

### 1. 零延迟硬件级多点触控引擎 (`pjsk_keybinds.py`)
- **内核级事件捕获**：使用 `evdev` 直接读取 `/dev/input/event*` 原始扫描码，无需经过 XWayland 或桌面合成器，输入链路延时低至 1ms 以内；
- **虚拟硬件触控板**：通过 `uinput` 在内核中注册符合 Linux Multi-Touch Type B 规范的虚拟触摸屏，拥有 10 个独立硬件触控槽位（Slot 0~9）；
- **FIFO 槽位队列调度**：旧版触控映射常使用 `min(free_slots)`，高速连续敲击同一键位时会一直复用 Slot 0，导致松开与下一次按下的事件落在同一个游戏渲染帧而被丢弃。本项目采用 FIFO 队列调度，刚抬起的槽位排入队尾，连击必定分配新槽位；
- **长条心跳防断（Keepalive）**：游戏对静止不动的触点容易产生判定衰减。后台守护线程每隔 30ms 对当前按住的音轨发送 Y 轴 ±1 像素的亚像素微动，保证长条音符（Hold/Slide）全程完美连击；
- **上滑微步插值（Flick）**：按下空格键时，后台自动在 12ms 内以 3ms 间隔向判定线上方 280 像素做 4 阶线性插值滑动手势，滑完自动抬起，实现完美的 Flick 判定。

### 2. KDE Wayland 专属无穿透透明 HUD (`pjsk_overlay.py`)
- **纯透明无边框渲染**：利用 PySide6 绘制符合 1920x1080 标准屏幕的高对比圆角键位徽章；
- **完全鼠标输入穿透**：开启 `WindowTransparentForInput` 与 `WA_TransparentForMouseEvents`，点击任何位置均直接穿透到下层 Waydroid 游戏画面，丝毫不影响正常 UI 交互；
- **KWin Scripting 强制定格**：利用 KDE KWin 的 D-Bus 脚本接口加载运行时脚本，赋予窗口 `keepAbove = true`、`skipTaskbar = true`，突破 Wayland 协议对常规置顶的限制；
- **科学视野布局**：判定框上方区域 100% 留空，将双轨合击键（Z/X/C/V/B）显眼标注在判定线**正下方**，绝不遮挡音符下落视线。

## 二、Waydroid 鼠标左键点击交互指令

### 1. 为什么默认鼠标左键在游戏里点不动？
Unity 引擎开发的安卓游戏（如 PJSK、原神、明日方舟等）默认只接收触屏（TouchScreen）输入事件，对于桌面鼠标左键发送的指针事件（Pointer Event）会被游戏视作无效输入。

### 2. 开启鼠标左键模拟触控（Fake Touch）
通过 Waydroid 提供的属性配置接口，将鼠标点击映射为真实触屏触摸：

#### 方案 A：仅为 PJSK 游戏单独开启（强烈推荐）
仅在 PJSK 运行时模拟触控，不影响其他安卓日常应用中的鼠标选中文本与滚轮滑动：
```bash
# 适用于国际服与日服
waydroid prop set persist.waydroid.fake_touch "com.sega.ColorfulStage.en,com.sega.pjsekai"
```

#### 方案 B：全局对所有安卓应用开启
```bash
waydroid prop set persist.waydroid.fake_touch '*'
```

### 3. 重启 Waydroid 容器使配置生效（必须执行）
设置属性后，必须重启容器守护进程以载入驱动层配置：
```bash
sudo systemctl restart waydroid-container
```
*(或者在终端中重启用户会话：`waydroid session stop && waydroid session start`)*

### 4. 备用指令（针对特定系统固件）
如果所使用的 Waydroid 镜像支持直接修改系统全局设置，亦可执行：
```bash
# 开启鼠标强制模拟触摸
sudo waydroid shell settings put system force_mouse_as_touch 1

# 关闭恢复默认
sudo waydroid shell settings put system force_mouse_as_touch 0
```

### 5. 清除/恢复默认鼠标行为
若后续想撤销 Fake Touch 配置，执行以下命令并重启容器即可：
```bash
waydroid prop set persist.waydroid.fake_touch ""
sudo systemctl restart waydroid-container
```

## 四、环境依赖与安装

### 1. 系统依赖（Fedora / RHEL）
```bash
sudo dnf install -y python3-evdev python3-pyside6
```

### 2. 免密码访问输入设备（可选，提升体验）
`pjsk_keybinds.py` 需要读取底层 `/dev/input/event*` 与创建 `/dev/uinput`。若不想每次启动输入 sudo 密码，可将当前用户加入 `input` 组：
```bash
sudo usermod -aG input $USER
echo 'KERNEL=="uinput", GROUP="input", MODE="0660"' | sudo tee /etc/udev/rules.d/99-uinput.rules
sudo udevadm control --reload-rules && sudo udevadm trigger
```
*(设置后重新登录或重启系统生效)*

## 五、快速使用指南

### 1. 一键启动
进入项目目录后，直接运行启动脚本：
```bash
./start_pjsk.sh
```
脚本将依次启动：
1. 后台拉起无焦点穿透的透明置顶 HUD 字幕；
2. 启动底层按键映射驱动（如未配置 udev 规则，终端会提示输入 sudo 密码）；
3. 切换到 Waydroid PJSK 游戏窗口即可使用全键盘畅快打击！

### 2. 安全退出
在终端中按下 `Ctrl + C`，脚本将自动拦截退出信号并同步清理后台的 Overlay 字幕进程与虚拟触控设备。

## 六、高级配置与微调

### 单独启动与微调参数

#### 1. 调整 HUD 判定线垂直高度与不透明度
如果显示器或游戏窗口不是全屏 1080P，可通过参数微调 HUD 位置：
```bash
# Y 轴向下偏移 20 像素，透明度设为 80%
python3 pjsk_overlay.py --offset-y 20 --opacity 0.8

# 显示底部的 1~12 小轨细分刻度
python3 pjsk_overlay.py --show-sub
```

#### 2. 诊断触控延迟
启动按键映射时加入 `-v` 参数，可实时打印内核物理按键时间戳到 uinput 写入的延迟数据（通常 ≤ 1.2ms）：
```bash
sudo python3 pjsk_keybinds.py -v
```
